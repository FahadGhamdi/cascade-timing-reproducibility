# Archived search candidates — not an accepted bibliography

These JSON files were preserved from the recovered project. A filename alone does not establish a match. In particular, qrf2006.json, casper2022.json, cawley2010.json and mentch2022.json contain rejected fuzzy-search candidates for other works. They must not be treated as bibliographic authority. The active REFERENCE_AUDIT.csv identifies the correct primary records and compares actual titles. The original files are preserved to make this distinction auditable.
