# Targeted literature matrix for the next BRACE study

Reviewed 12 September 2026. Scope: 22 closely relevant methodological/domain references, not an exhaustive or systematic review. No external published scores are merged with BRACE scores. A = authoritative abstract/metadata consulted; P = relevant paper sections consulted; R = author repository inspected statically. A repository inspection does not certify reproduction. Prior manuscript references remain historical; this matrix informs the new experiment contract.

## Baseline selection reached in this phase

1. Core distributions: existing Hurdle, QRF and NGBoost; add ordinary Poisson/NB and a conditional empirical reference. Keep an unconditional reference for continuity.
2. Main information contrast: within each chosen family, prefix size versus prefix size plus a fixed small temporal feature set, under matched tuning resources.
3. Domain reference: CASPER is the first finite-horizon feasibility candidate; retain the author-trained TiDeH route as a documented alternative. An adaptation is named as an adaptation.
4. Modern methods: choose one justified by available inputs and runtime, rather than importing an entire benchmark suite. CasTemp/CascadeBench is a reference for protocol design; static inspection found optional simplified behavior in integrated code paths, so it must not be advertised as exact reproduction of every included model.
5. Primary comparison remains a distribution comparison. A point-only method can inform a separate point-loss table; deciding whether a complete process distribution is essential belongs in the finalized experiment contract.

## Novelty statement we can defend at this stage

The proposed contribution is an empirical study of the incremental predictive value of temporal information for recorded count distributions across two data sources, with matched within-family ablations and count-appropriate calibration assessment. This is a research design, not an achieved result or a proven literature gap. The study must demonstrate a useful insight beyond a ranking table. No claim of causal containment, universal dominance, or first uncertainty-aware cascade prediction is justified.
