## Small set of remaining decisions

1. The restricted-input empirical scope is fixed, and the bounded supplementary control and editorial integration are complete. No new experiment is automatically scheduled.
2. Have a domain consultant assess whether its empirical insight is sufficient for the intended venue. A request for a specialized model comparison should identify the precise missing claim it would resolve.
3. Complete authorship, declarations and the public reproducibility deposit. Verify references in the chosen journal style.
4. Keep this TEST result fixed. An actual implementation defect requires a transparent correction record; a desired improvement in a score is not such a defect.

Text/NLP modeling remains a separately scoped future project. The existing TEST cohort must not become the tuning set for a new paper presented as fresh confirmation.
